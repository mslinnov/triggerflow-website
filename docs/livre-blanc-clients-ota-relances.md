# Relances du guide du client OTA (brouillon)

Trois e-mails envoyés après le téléchargement du guide depuis `/fr/lp/clients-ota-hotel-livre-blanc` (slug
`clients-ota`). Ils seront saisis dans TriggerFlow par le chantier de câblage (flow activé avant de rattacher le
formulaire).

Règles d'écriture :
- **Aucun nom propre** : le formulaire ne demande que l'adresse e-mail, une formule d'appel nominative s'afficherait
  vide. « Bonjour, » seul.
- Aucun tiret cadratin, aucun chiffre sans source : les taux viennent du guide, donc de l'étude.
- Les passages entre crochets attendent l'étude ou une décision.
